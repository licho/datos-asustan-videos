# Datos que Asustan — videos

Reels verticales de terror cómico y datos curiosos. Aquí vive todo: el motor de animación (`lib/`), los guiones, las especificaciones de cada video (`specs/`), las voces y los videos finales que se programan en Metricool.

- **Cómo producir un video y reglas del canal:** [`CLAUDE.md`](CLAUDE.md)
- **Temas hechos y pendientes:** [`IDEAS.md`](IDEAS.md)
- **Piezas reutilizables:** [`lib/CATALOGO.md`](lib/CATALOGO.md)

Requisitos: Python 3 con `pip install -r requirements.txt`, `ffmpeg` y la fuente DejaVu Sans (`/usr/share/fonts/truetype/dejavu/`).
